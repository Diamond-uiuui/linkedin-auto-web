Конфиденциальность Writer Helper (WH)

Обновлено 29 октября 2026

WH — личное пространство владельца для идей, голосовых заметок и черновиков. Публичный сайт содержит интерфейс; личные материалы доступны через защищённый сервер после входа.

Какие данные используются

Идеи, тексты черновиков и загруженные файлы хранятся в Cloudflare D1 и закрытом R2. При входе через GitHub проверяется идентификатор аккаунта владельца; токен GitHub не сохраняется. При подключении LinkedIn сохраняются идентификатор и имя профиля. Токен LinkedIn используется для проверки профиля и не сохраняется. Пароли социальных сетей WH не получает.

Обработка с помощью AI

При запуске подготовки черновика, расшифровки или анализа изображения соответствующий текст, аудио или изображение передаётся OpenAI через API. Исходные файлы сохраняются отдельно от результатов. Текстовые и визуальные запросы Responses используют параметр store:false. Условия обработки провайдеров применяются к их услугам.

Хранение и доступ

Секреты API хранятся только на сервере. Сессия действует до семи дней; браузер хранит её до закрытия сессии вкладки или выхода. Незавершённые OAuth-запросы действуют десять минут, одноразовые коды входа — 90 секунд. Текущий текст редактора и локальные версии могут оставаться в хранилище браузера. Незагруженные файлы находятся только в памяти открытой вкладки.

Облачные материалы не удаляются автоматически. Управление ими выполняет владелец приложения. Отключение LinkedIn удаляет связь профиля, но не удаляет идеи и черновики. Для отзыва доступа со стороны социальной сети используйте её настройки подключённых приложений.

Провайдеры

Интерфейс размещён на GitHub Pages; сервер и хранилище — Cloudflare; AI — OpenAI. GitHub и LinkedIn используются для авторизации. Провайдеры могут обрабатывать технические данные по своим политикам. WH не продаёт личные материалы и не использует рекламные трекеры.

Эта версия рассчитана на личное использование владельцем, а не на публичную регистрацию пользователей. Вопросы о данных следует адресовать владельцу, предоставившему вам доступ.
